Chaser Game

Required libraries:
pygame and sys 

Instructions:
to start the game run the python file and press "space" to start.
Use either "aswd" or the arrow keys to move around the graphs and try to reach the goal(the white circle) while avoiding the chaser(red circle). 
If you either lose or win press "r" key to restart the game or press "q" to quit it. 


Note: as of now the game is very simple and straight foward. Later on will decide to improve on the map size and difficult and including more path finding algorithms.
